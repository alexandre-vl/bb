- after/: the v3 prototype on the same public snapshot; agents are simulated

- v3.1/: menus anchored to their trigger (before/after), and the loading states the prototype simulates
- v3.2/: the pull request status as a menu, bb's diff colours and size bar, the branch copy chip (before/after and a recording)
